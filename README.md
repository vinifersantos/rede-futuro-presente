# Rede Futuro Presente

Projeto acadêmico desenvolvido para a disciplina **Desenvolvimento FrontEnd - Experiência Prática 1**.

O site apresenta uma organização social fictícia voltada à inclusão digital e à capacitação tecnológica de jovens. O projeto foi criado para praticar estrutura semântica em HTML5, navegação entre páginas, formulários, acessibilidade e validações nativas.

## Páginas

- `index.html`: apresentação da organização, missão e informações de contato.
- `projetos.html`: projetos sociais, campanhas de doação e oportunidades de voluntariado.
- `cadastro.html`: formulário para doadores e voluntários.

## Recursos utilizados

- HTML5 semântico;
- `fieldset` e `legend` para agrupar os campos do formulário;
- rótulos associados aos campos para melhorar a acessibilidade;
- validações com `required`, `pattern`, `minlength`, `maxlength` e tipos de entrada específicos;
- atributos de preenchimento automático e teclado adequado para dispositivos móveis.

## Decisão sobre privacidade

O formulário não solicita CPF porque esse dado não é necessário para registrar o interesse em doar ou participar como voluntário. A decisão reduz a coleta desnecessária de dados pessoais e preserva a privacidade do usuário.

## Como visualizar

Baixe ou clone o projeto e abra o arquivo `index.html` em um navegador. Não é necessário instalar dependências.

## Observação

Este projeto possui finalidade exclusivamente acadêmica. Os nomes, endereços e informações de contato apresentados são fictícios.
